CAMBIOS IMPLEMENTADOS - GESTIÓN CONTRATACIÓN PRO

1. Dashboard administrador:
   - Se dejó solo Gestión Contratación.
   - Se retiraron los cards de Gestión Documental y Gestión Vacacional del Centro de Control.
   - Se agregó dashboard de contratación visible con indicadores y acceso al dashboard completo.

2. Requerimientos / tickets:
   - Se mantiene ticket de contratación con tabla, filtro y opción de eliminar.
   - Mejor organización para el embudo de requerimientos.

3. Nuevos / reingresantes:
   - Formulario ampliado: DNI, trabajador, celular, correo, dirección, cargo, sede, área, actividad, modalidad, fecha ingreso, jefe, cuenta bancaria, talla de indumentaria y contacto de emergencia.
   - Preparado para foto de trabajador y posterior uso en fotocheck.
   - Preparado para huella biométrica ZK9500 como carga/evidencia.
   - Tabla con filtro, guardar y eliminar.

4. Control médico:
   - Se agregaron campos de tipo de examen, clínica/proveedor, protocolo médico, riesgo del puesto, fecha programada, fecha resultado, vencimiento, estado, aptitud médica, restricciones, recomendaciones, responsable de seguimiento, contacto proveedor, costo y archivo de resultado.
   - Se guarda información ampliada y se muestra en tabla con filtro y eliminación.

5. Capacitación con videos:
   - Se agregó carga de video MP4/WEBM/MOV, URL externa, tipo de video, duración, preguntas, intentos, aprobador, nota, fechas, evidencia y observación.
   - Tabla con filtro, guardar y eliminar.

6. Indumentaria y fotocheck:
   - Mejor descripción de EPP, uniformes, cargo y validación previa a NISIRA.
   - Tabla con filtro y acciones.

7. Fotocheck / Zebra ZC300:
   - Se preparó flujo para usar foto tomada en Alta, validar DNI, plantilla CR80, impresión Zebra ZC300, reimpresión, cargo firmado y lote de impresión.
   - Se agregaron campos de datos de impresión: impresora, serial/IP/USB y plantilla CR80.

8. Interfaz general:
   - Se agregó estilo PRO para reducir espacios vacíos, mejorar legibilidad, aprovechar mejor el ancho y hacer tablas con scroll horizontal.
   - Se agregaron filtros tipo búsqueda en módulos operativos.
