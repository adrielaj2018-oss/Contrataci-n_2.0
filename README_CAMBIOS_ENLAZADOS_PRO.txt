CAMBIOS PRO IMPLEMENTADOS - MÓDULOS ENLAZADOS

1. Se agregó una Base Operativa de Trabajadores enlazada en Nuevos/Reingresantes, Control Médico, Capacitación e Indumentaria.
2. Los trabajadores registrados en Nuevos/Reingresantes aparecen automáticamente en los demás módulos.
3. Se agregó selección individual y masiva de trabajadores para avanzar estados del proceso.
4. Estados masivos disponibles: General, Médico, Capacitación, Indumentaria, NISIRA y Biometría.
5. Se agregaron búsquedas/filtros tipo NEXT para DNI, trabajador, requerimiento, sede y estado.
6. En Control Médico, Capacitación e Indumentaria se agregó selector por DNI con base de trabajadores registrados.
7. Se mantiene opción de ficha del trabajador desde la base operativa.
8. Se mejoró la organización visual de tablas y formularios para aprovechar mejor el espacio.
