MODULOS AGREGADOS - GESTION CONTRATACION / NISIRA

- Configuración de Base URL, endpoint de trabajadores, referencia API Key y modo PRUEBA/PRODUCCION.

3. Documentos de postulantes
- Control por sede, requerimiento y actividad.

4. Datos completos
- Control de reporte completo por sede/requerimiento/actividad.

5. Fotocheck
- Control de fotos, descarga de imágenes y cargos de fotocheck.
